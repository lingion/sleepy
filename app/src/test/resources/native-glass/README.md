`drag-matrix.csv` contains actual delivered touch inputs and observed native
presentation-frame lens transforms, exported from the iOS 26.5 native reference
harness on November 12, 2026. It covers UIKit segmented control and UITabBar,
forward/reverse requested velocities of 100/900 pt/s, repeated twice. iOS points
are used as the corresponding Android dp distance for this geometry comparison.

Each group starts 100 ms before the first changed touch position, preserves the
held stop (about 267 ms), and ends 650 ms after touch up. Positions are signed
displacements from the initial touch; scales are the recorded m11/m22 lens
transforms before outer dock platter scaling. Input times are actual touch
sample times. The fixture contains measured data, not values generated by the
Android implementation.

Original run identifiers:

- Segment: `-_NativeReferenceTests_testDragVelocityMatrix_-A2BF6EC8-C7A6-40BB-AF92-723690A9A08F`
- Dock: `-_NativeReferenceTests_testDragVelocityMatrix_-4AEBDB2F-E5D0-4E11-9E63-2DE75289B029`

The model is an approximation. Tests bound its residual against the recordings;
they do not assert that its spring parameters are Apple's internal parameters.
