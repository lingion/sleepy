# Sleepy v1.0.18

### Direct import covers 183 schools
Before, timetable data had to be entered manually or imported from a file. The school list now contains 183 entries with academic-system URLs and protocol types. HEU direct import was verified end to end; other schools may depend on their live systems.

### School search accepts pinyin
Search now matches Chinese names and pinyin initials, with a live result count.

### Pick a week from the home screen
Tap the week label to open a week picker. Selecting another week is a temporary inspection and returns to the current week afterward.

### Widgets can scroll through courses
Today and TwoDay widgets no longer stop at a small fixed course count. Switching or creating a timetable also refreshes widgets.

### Import and export round trips are fixed
Imported ICS and exported text now parse correctly in both directions.

# Sleepy v1.0.18

### 直连导入覆盖 183 所学校
之前只能手动录入或从文件导入课表。现在学校列表包含 183 个带教务 URL 和协议类型的条目。哈工程直连导入已完成端到端核验，其他学校仍取决于各自的在线教务系统。

### 学校搜索支持拼音
现在可以按中文名或拼音首字母搜索，并实时显示匹配数量。

### 首页可以选择周次
点击周次标签即可打开周次选择器。选择其他周用于临时查看，之后会回到当前周。

### 小组件可以滚动查看课程
Today 和 TwoDay 小组件不再受固定课程数量限制。切换或新建课表后也会刷新小组件。

### 导入导出双向解析修正
导入的 ICS 和导出的文本现在可以正常双向解析。

### 构建
- Release 标签：`v1.0.18`
