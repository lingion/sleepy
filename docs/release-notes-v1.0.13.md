# Sleepy v1.0.13

### Import now opens configuration before saving
Before, importing a timetable skipped the configuration page and wrote courses without period times, a start date, or a table name. The flow now opens configuration after parsing, then saves only after the user confirms the period times, start date, and table name.

### Build
- Release tag: `v1.0.13`
- APK: `sleepy-v1.0.13-arm64-release.apk`

# Sleepy v1.0.13

### 导入后先配置再保存
之前，导入课表跳过了配置页，课程会在没有节次时间、开学日期和课表名称的情况下直接写入。现在解析完成后会先打开配置页，确认节次时间、开学日期和课表名称后才保存。

### 构建
- Release 标签：`v1.0.13`
- APK：`sleepy-v1.0.13-arm64-release.apk`

— Lingion
