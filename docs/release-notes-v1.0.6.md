# Sleepy v1.0.6

### Course cards align with the timetable grid
Before, course cards could sit slightly above or below the grid lines, and some rendering states showed incorrect text or colors. The CourseTableView layout and rendering have been corrected so cards align with their periods.

# Sleepy v1.0.6

### 课程卡片与课表网格对齐
之前，课程卡片可能会和网格线有轻微上下错位，部分渲染状态下文字或颜色也显示不正确。现在已修正 CourseTableView 的布局和渲染，课程卡片会对应到正确的节次位置。

### 构建
- Release 标签：`v1.0.6`
- 标签对应 Gradle 配置记录的 versionName 为 `1.0.4`、versionCode 为 `3`
