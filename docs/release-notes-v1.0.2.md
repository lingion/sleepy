# Sleepy v1.0.2

### The empty state no longer shows a phantom workspace
Before, a fresh installation displayed an extra empty workspace even though no timetable existed. The empty state now goes directly to timetable import or creation, without a placeholder workspace.

### The home screen no longer carries placeholder branding
Before, the empty home screen used a large placeholder header. It has been removed so the first useful action is easier to find.

### Build
- versionName in the tagged build: `1.0.0`
- versionCode: `1`

# Sleepy v1.0.2

### 空状态不再显示多余的占位课表
之前，刚安装时即使没有课表，首页也会显示一张空白工作区。现在空状态会直接提供导入或创建课表的入口，不再生成占位课表。

### 首页去掉占位品牌内容
之前，空首页顶部有一块较大的品牌占位。现在已移除，打开后更容易找到第一个可用操作。

### 构建
- 标签对应构建的 versionName：`1.0.0`
- versionCode：`1`

— Lingion
