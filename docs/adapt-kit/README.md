# Sleepy 课表采集 · 完整操作手册

> 本手册面向想让自己学校支持教务直连的同学。全程不需要任何编程知识,照着做就行。
> 总耗时约 10 分钟:采集 5 分钟,提交 2 分钟,剩下的时间是等。

---

## 0. 开始之前

**我需要做什么?**
用我们提供的工具,把你学校教务系统的页面和数据"原样打包"成一个 zip 文件,发给我们。剩下的适配工作全部由我们完成。

**为什么需要我来做?**
适配一个学校,最难的一步是拿到该校教务系统的真实页面和接口——这些只有在校生能拿到。你采集一次,你的学校就永久支持教务直连。

**我的学校用"某某教务系统"可以做吗?**
不用管学校用什么系统。采集工具不认识"系统类型"这回事,它把浏览器里能看到的一切原样打包。我们拿到包就能写适配。

**开始前的检查清单:**

- [ ] 一台 Windows、macOS 或 Linux 电脑(手机不行)
- [ ] 电脑上装有 Chrome 或 Edge 浏览器(没有也行,见 2.4)
- [ ] 能登录学校的教务系统(可能需要校园网或学校 VPN)

---

## 1. 下载采集工具

打开 Sleepy 的 Release 页面:<https://github.com/lingion/sleepy/releases>

找到最新版本,在下方 **Assets** 资产区,按你的电脑下载对应文件:

| 你的电脑 | 下载这个文件 |
|---|---|
| Windows 10/11(64位) | `sleepy-collector-windows-amd64.exe` |
| Mac(Apple 芯片 M1/M2/M3/M4) | `sleepy-collector-macos-arm64` |
| Mac(Intel 芯片) | `sleepy-collector-macos-amd64` |
| Linux(64位) | `sleepy-collector-linux-amd64` |

> 不确定 Mac 是什么芯片?点屏幕左上角苹果菜单 →「关于本机」:写着 "芯片 / Chip" 且是 Apple M 开头,选 arm64;写着 "处理器 / Processor" 且是 Intel,选 amd64。

下载完成后,文件在你的**下载**文件夹里。

---

## 2. 运行采集工具

### 2.1 打开工具

**Windows:**

双击下载的 `.exe`。Windows 可能弹一个蓝色警告框「Windows 已保护你的电脑」——因为工具没有购买微软代码签名证书,Windows 对所有没签名的陌生程序都会这么提示,不针对我们。

- 点警告框上的「更多信息」
- 再点「仍要运行」

工具就正常打开了。如果 Defender 或杀毒软件直接把文件删了(误报),到 Windows 安全中心 →「病毒和威胁防护」→「保护历史记录」里找到这条记录,选「还原」;还原后同一路径可能再拦一次,选择「允许」把它加入允许列表。嫌麻烦可以改用第 6 章的 F12 脚本方式,不用下载任何程序。

**macOS:**

双击下载的文件。可能遇到两种提示,都是因为工具没有购买苹果开发者签名:

- 「无法打开,因为无法验证开发者」或「Apple 无法检查其是否包含恶意软件」:
  1. 先点弹窗里的「完成」(不要点"移到废纸篓")
  2. 打开 **系统设置 → 隐私与安全性**,滚到最下面,「安全性」一栏会出现「**仍要打开**」按钮,点它
  3. 弹窗再出现一次,点「**打开**」

  这是苹果官方给出的办法,做一次以后就能正常双击。
- 「"xxx"已损坏,无法打开,建议您把它移到废纸篓」:别删,文件是完好的。打开「终端」(启动台搜"终端"或 Terminal),粘贴这行命令后回车(把文件名换成你实际的):
  ```
  xattr -d com.apple.quarantine ~/Downloads/sleepy-collector-macos-*
  ```
  然后再双击打开。

**Linux:**

打开终端执行(在文件所在目录):

```bash
chmod +x sleepy-collector-linux-amd64
./sleepy-collector-linux-amd64
```

> Ubuntu 22.04 及以后的文件管理器里双击不再直接运行程序,会提示没有权限——所以推荐直接用上面两条终端命令。如果运行报 "Permission denied" 就是少了 chmod 那步。

工具打开后是一个黑色文字窗口,显示:

```
=====================================================
  Sleepy 课表适配采集工具 v1.0
=====================================================

流程:输入教务网址 → 弹出浏览器 → 你在里面登录并打开课表 →
      点页面右下角绿色按钮 → 自动生成 sleepy-adapt.zip

请输入教务系统网址(例如 jwxt.xxx.edu.cn):
```

### 2.2 输入教务网址

把你学校教务系统的网址输入进去,按回车。

就是你在电脑浏览器里平时查课表用的那个网址,带不带 `https://` 都行,工具会自动补全。

> 教务网址一般长这样:`jwxt.某某大学.edu.cn`、`jw.某某.edu.cn`,或学校信息门户里「教务系统」链接指向的地址。不确定的话先在浏览器里打开试一下,能到登录页就没错。

### 2.3 登录 → 打开课表 → 点绿色按钮

回车后,工具自动弹出浏览器窗口,打开你学校的教务登录页。接下来**全部在浏览器里操作**:

1. **正常登录**。输学号密码、输验证码、该扫码扫码——和平时查课表完全一样
2. **找到课表页面**。入口名字通常是「我的课表」「学生课表」「课表查询」「周课表」,进到能看到本学期课表的页面,停在那里
3. **点页面右下角的绿色按钮**「✓ 课表没问题,一键采集打包」

点完后按钮变成「正在打包,请不要关闭页面…」。

> - 期间**不要关浏览器窗口**,也**不要关黑色文字窗口**
> - 打包需要一两分钟(要把页面用到的所有文件都收进来),期间页面可能有点卡,正常
> - 找不到绿色按钮?在**黑色文字窗口**里按一次回车,直接触发打包

### 2.4 没装 Chrome / Edge?

工具会提示并自动下载一个官方浏览器内核(约 190MB,只下载一次),国内网络直连可下(走国内镜像)。保持网络畅通等它下完即可。

### 2.5 采集完成

黑色窗口显示:

```
✓ 采集完成: /Users/你的用户名/Downloads/sleepy-adapt-XXXXXX.zip
```

同时你的**下载文件夹自动打开**,里面就是 `sleepy-adapt-XXXXXX.zip`——这个文件是采集成果。

黑色窗口按回车关闭,浏览器可以关了。

## 3. 提交采集包

**方式 A(推荐):发邮件**

把 `sleepy-adapt-xxxxxx.zip` 作为附件发到:<lingion@hrbeu.edu.cn>

邮件正文写上你**学校的全名**和教务系统网址,例如:"XX大学,jwxt.xx.edu.cn"。这样我们能更快定位。

**方式 B:发 GitHub issue**

1. 打开适配申请:<https://github.com/lingion/sleepy/issues/new?template=school_adaptation.yml>
2. 填上学校全名和教务网址
3. 把 zip 拖进正文,提交

两种方式处理速度一样。发 issue 便于跟进进度。

## 4. 隐私:包里有什么

**采集不到的**:你的密码(工具从不读取密码框)、验证码图片、Cookie 的具体内容。

**会采集到的**:课表本身(课名/教师/教室/时间)、页面 HTML、教务系统的代码文件、浏览器存储。

**可能带出的个人信息**:你的**姓名和学号**(教务系统经常把它们嵌在页面和接口数据里);浏览器存储里可能有过期登录令牌(离开页面就失效)。

**提交前建议自查(可选,两分钟):**

1. 用压缩软件打开 zip,把里面的文件解压到临时文件夹
2. 用文本编辑器(记事本)在解压出的文件里搜索你的**姓名**,再搜你的**学号**
3. 搜到的改成 `XXX`,改完重新压缩再发。会搜到很多处,都改掉即可,不影响适配
4. 搜不到就直接发

嫌麻烦也可以不做这步直接发——我们只在适配时看这个包,不会公开它,适配完成后建议你自行删除本地副本。

## 5. 出问题了?

| 现象 | 办法 |
|---|---|
| 教务网址打不开/一直转圈 | 多数学校教务只在校内可达。回学校连校园网,或连学校 VPN 再试 |
| 绿色按钮找不到 | 停在课表页等两秒;还不行就在黑色窗口按回车直接打包 |
| 打包失败/报错 | 把黑色窗口里的报错**截图**,连同学校全名发到 lingion@hrbeu.edu.cn |
| Windows 提示「Windows 已保护你的电脑」 | 「更多信息」→「仍要运行」,详见 2.1 |
| Windows 杀毒软件把 exe 删了 | 安全中心「保护历史记录」→「还原」→「允许」,详见 2.1;嫌麻烦换 F12 方式 |
| macOS「无法验证开发者/已损坏」 | 见 2.1 的「仍要打开」或 `xattr` 命令 |
| Linux 报 `Permission denied` | 少了 `chmod +x` 那步,见 2.1 |
| 浏览器窗口闪退 | 黑色窗口里会有报错信息,截图发邮箱 |
| 其他 | 发邮件说明现象,附截图 |

## 6. 备选方式:F12 控制台脚本

杀毒软件拦工具、或公司/机房电脑不允许运行下载程序时,用你自己浏览器的 F12 控制台完成同样的采集。脚本全程在你已登录的浏览器里跑,不向任何第三方发送数据。

1. 用电脑 Chrome 或 Edge 正常登录教务系统,进到课表页面
2. 按键盘 `F12`(或右键页面空白处 →「检查」),切到 **Console / 控制台** 标签
3. 打开 [collect.js](collect.js) → 点右上角 **Raw** → `Ctrl+A` 全选 → `Ctrl+C` 复制
4. 回到浏览器控制台,点一下输入区,`Ctrl+V` 粘贴,按回车

第一次粘贴 Chrome 会弹一个红色警告并不让粘——在输入区手动敲入四个单词 `allow pasting` 回车,然后再粘一次代码。这是 Chrome 防骗保护(防止坏人骗你在控制台粘代码盗号),我们要粘自己的采集脚本,所以按它说的解锁即可。

页面右下角出现黑色小面板「Sleepy 课表采集器」:

5. 建议**先刷新一次页面**(F5),等课表重新显示,更保险
6. 点面板上的 **[生成采集包]** 绿色按钮,等浏览器自动下载 `sleepy-adapt.zip`

> 打包时页面卡几秒到几十秒,正常。没自动下载就再点一次绿色按钮。

之后的提交(第 3 章)、隐私自查(第 4 章)和方式一相同。

### 终极兜底:手动采集

脚本也被学校安全软件拦掉时,手动来(信息少一些,适配会慢些):

1. 登录页按 `Ctrl+S`,保存类型选「网页,仅 HTML」
2. 进到课表页,再 `Ctrl+S` 存一份
3. 课表页面完整截图 1-2 张
4. 这些文件一起发到 lingion@hrbeu.edu.cn 或发 issue,注明学校全名

## 7. 采集包里有什么(给想深究的人)

不管哪种方式,采集都不预设你的学校是哪种系统——把浏览器里能看到的一切原样打包,按目录组织:

| 目录 | 内容 |
|---|---|
| `1-dom/` | 每个页面、每个 iframe 的完整 DOM(课表已渲染的话,数据就在这里) |
| `2-inline/` | 页面内联的 `<script>` / `<style>` 源码 |
| `3-res/` | 页面加载过的所有 HTML/CSS/JS/JSON,逐个重新抓取的原样内容 |
| `4-net-live/` | 每个网络请求的完整记录(请求体+响应体) |
| `4-net-replay/` | 数据接口的重放响应(方式一在底层抓包,这层基本用不上) |
| `5-storage/` | localStorage / sessionStorage |
| `6-logs/` | 浏览器完整网络日志、发现的所有 URL、抓取失败清单 |
| `INDEX.txt` | 全包清单:每个文件是什么、从哪来的 |

三路信息互为备份(渲染 DOM / 接口响应 / 请求记录):某一路拿不到,另外两路也够。Sleepy 现有 25 种教务协议解析器(正方、强智、金智、URP、青果等),遇到新系统,我们照包里的真实数据写新解析器。

适配完成后,你的学校会出现在下个版本的更新说明里。
