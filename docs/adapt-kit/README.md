# 让你的学校支持教务直连 — 5 分钟采集教程

Sleepy 的教务直连是按学校逐个适配的。没适配的学校导入会失败,因为每个学校的教务系统返回的数据格式都不一样。

适配一个学校,最难的一步是拿到该校教务系统的真实页面、代码和数据接口——这些只有在校生能拿到。你花 5 分钟采集一份完整"快照"发给我们,剩下的适配工作全部由我们完成。**你不需要懂任何技术,采集工具也不需要你的学校是某种特定类型——它把浏览器里的一切原样打包成 zip。**

**两种采集方式,选一个就行:**

- **方式一(推荐):采集小工具** — 下载一个小程序,双击打开,输入教务网址,会弹出一个浏览器窗口,你在里面正常登录、打开课表,点一下页面上的绿色按钮,压缩包就自动生成了。
- **方式二:F12 控制台脚本** — 用自己电脑上的浏览器登录教务系统,按 F12 粘贴一段代码。适合电脑不允许运行下载程序的情况。

## 方式一:采集小工具(推荐)

1. 从 [Sleepy 的 Release 页面](https://github.com/lingion/sleepy/releases) 下载「课表采集工具」(Windows / macOS 按系统选)
2. 双击运行,输入你学校的教务系统网址(就是平时查课表用的那个网址)
3. 会自动弹出一个浏览器窗口,**在里面正常登录**(验证码、短信验证都和平时一样)
4. 打开你的课表页面,点页面右下角的绿色按钮「课表没问题,一键采集打包」
5. 等它提示完成,压缩包 `sleepy-adapt-xxxx.zip` 已存到你的**下载**文件夹

> - 需要电脑上装有 Chrome 或 Edge 浏览器(大部分电脑都有)
> - 采集打包需要一两分钟,期间别关那个浏览器窗口
> - 如果安全软件拦截,换方式二

## 方式二:F12 控制台脚本

用自己电脑上的浏览器完成,分四步:

### 第一步:准备

用电脑 Chrome 或 Edge 打开教务系统,输入学号密码登录。

> 手机浏览器不行,得用电脑。教务系统一般要连校园网或学校 VPN 才能访问。

### 第一步:准备

用电脑 Chrome 或 Edge 打开教务系统,输入学号密码登录。

> 手机浏览器不行,得用电脑。教务系统一般要连校园网或学校 VPN 才能访问。

### 第二步:找到课表页面

登录后,在教务系统里找到"我的课表"、"学生课表"、"课表查询"这类入口,进到能看到你这学期课表的页面,停在那里。

### 第三步:运行采集脚本

1. 按键盘上的 `F12`(或者右键页面空白处 → 选"检查"/"审查元素")
2. 在弹出的面板里找到 **Console / 控制台** 标签页
3. 回到这个页面,点 [collect.js](collect.js) → 右上角"Raw"按钮 → `Ctrl+A` 全选 → `Ctrl+C` 复制
4. 回到浏览器控制台,点击输入区域,`Ctrl+V` 粘贴,按**回车**

页面右下角会出现一个黑色小面板「Sleepy 课表采集器」。

5. 如果你的课表还显示在页面上,直接进第 6 步;为了更保险,可以先**刷新一次页面**(F5),等课表重新显示出来
6. 点面板上的 **[生成采集包]** 绿色按钮,等浏览器下载出 `sleepy-adapt.zip`

> - Chrome 第一次粘贴代码会提示让你先输入 `allow pasting`,照它说的输入那几个字母回车,再粘一次代码就行。这是 Chrome 的防骗保护,不是我们有问题。
> - 采集器运行时页面可能卡几秒到几十秒(它在打包页面用到的所有文件),属正常现象。
> - 如果没自动下载:重新点一下绿色按钮即可。

### 第四步:提交

**方式 A(推荐):发 issue**

1. 打开 [Sleepy 的适配申请 issue](https://github.com/lingion/sleepy/issues/new?template=school_adaptation.yml)
2. 填上你学校的名字和教务系统网址
3. 把刚下载的 `sleepy-adapt.zip` 拖进 issue 正文
4. 提交

**方式 B:发邮箱**

把 `sleepy-adapt.zip` 作为附件发到 Sleepy 应用**"关于"页面里公布的适配邮箱**,邮件正文写一句你学校的全名即可。

两种方式都行,处理速度一样。发 issue 方便跟进进度;适配完成后会在下个版本里出现。

## 关于隐私

- **采集不到**:你的密码(脚本从不读取密码框)、Cookie 内容(只记录名字)、验证码图片。
- **会采集到**:课表本身(课名/教师/教室/时间)、页面 HTML、教务系统的代码文件、浏览器存储。
- **可能残留个人信息**:你的姓名、学号(教务系统经常把它们内嵌在页面和接口数据里);浏览器存储里可能有登录令牌(离开页面就失效,但仍建议清理)。

提交前建议自查:用压缩软件打开 `sleepy-adapt.zip`,把里面的文件解压出来,用记事本搜你的**姓名**和**学号**,把搜到的改成 `XXX` 再重新压缩提交(会搜到很多处,都改掉即可,不影响适配)。搜不到就说明没有,直接发。嫌麻烦也可以直接发——我们只在适配时看这个包,不会公开它。

## 打不开教务系统?

有些学校在校外访问不了教务系统(连接超时/白名单拦截),回学校连校园网再试。如果 `F12` 之后粘贴代码没反应,把控制台里的红色报错截图发到 issue 里,我们看。

## 手动备份方案

上面脚本如果因为学校安全软件拦截跑不了,手动采集也行(麻烦一点,信息少一些):

1. **登录页**:在登录页面按 `Ctrl+S` 保存网页,选"网页,仅 HTML"
2. **课表页**:进到课表页面,同样 `Ctrl+S` 保存一份
3. **顺手截几张图**:课表页面的完整截图 1-2 张
4. 所有文件一起发到上面的 issue 或邮箱,注明学校名

> 手动方案拿不到课表接口的原始响应,适配会慢一些,可能还需要你补一次信息。

### 采集包里有什么(给想深究的人)

不管用哪种方式,采集都不预设你的学校是哪种教务系统——把浏览器里能看到的一切原样打包成 zip,按目录组织:

| 目录 | 内容 |
|------|------|
| `1-dom/` | 每个页面、每个 iframe 的完整 DOM(课表已渲染的话,数据也在这里) |
| `2-inline/` | 页面内联的 `<script>` / `<style>` 源码 |
| `3-res/` | 页面加载过的所有 HTML/CSS/JS/JSON 文件,逐个重新抓取的原样内容 |
| `4-net-live/` | 每个网络请求的完整记录(请求体+响应体)。方式二里特指粘贴脚本之后发出的请求 |
| `4-net-replay/` | 数据接口的重放响应(方式一在 CDP 层抓包,基本不需要这一层兜底) |
| `5-storage/` | localStorage / sessionStorage |
| `6-logs/` | 浏览器完整网络日志、发现的一切 URL、抓取失败清单 |
| `INDEX.txt` | 全包清单:每个文件是什么、从哪来的 |

多路信息互为备份(渲染 DOM / 接口响应 / 请求记录):就算某一路拿不到(接口有防护、页面结构特殊),另外几路也够我们完成适配。Sleepy 现有 25 种教务协议解析器(正方、强智、金智、URP、青果等),遇到新系统我们就照着包里的真实数据写新解析器。
