# Sleepy v1.0.17

### Export timetables in three formats
Before, there was no built-in export. Sleepy now exports WakeUp-compatible JSON, share text, and ICS calendar files, saving file-based exports under `Download/Sleepy/` and opening the system share sheet.

### Widgets show the selected timetable
Before, four widgets could display a fixed 24-period sample instead of your courses. They now resolve and render the active timetable.

### Build
- Release tag: `v1.0.17`
- APK: 20 MB

# Sleepy v1.0.17

### 课表支持三种导出格式
之前没有内置导出功能。现在可以导出 WakeUp 兼容 JSON、分享文本和 ICS 日历文件；文件型导出保存到 `Download/Sleepy/`，并打开系统分享面板。

### 小组件显示当前课表
之前，四种小组件可能显示固定的 24 节示例数据，而不是你的课程。现在会读取并渲染当前课表。

### 构建
- Release 标签：`v1.0.17`
- APK：20 MB
