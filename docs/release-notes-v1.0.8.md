# Sleepy v1.0.8

### Three timetable widgets are available
Before, the timetable only lived inside the app. Sleepy now provides Today, This Week, and Next Two Days widgets for the home screen.

### Widgets update after timetable changes
Before, adding, editing, or deleting a course could leave the widget showing old data until a later refresh. Timetable changes now trigger an immediate widget update, alongside the periodic refresh work.

### Widgets follow the app theme
The widgets now use the selected app color scheme, including dark mode.

### Build
- Release tag: `v1.0.8`
- The tagged Gradle configuration reports versionName `1.0.6` and versionCode `6`

# Sleepy v1.0.8

### 桌面新增三种课表小组件
之前，课表只能在 App 里查看。现在桌面可以添加今日课程、本周课表和今明两天三种小组件。

### 修改课表后小组件会更新
之前，添加、编辑或删除课程后，小组件可能继续显示旧内容，要等后续刷新。现在课表发生修改时会立即触发小组件更新，同时保留定期刷新任务。

### 小组件跟随应用主题
小组件现在使用应用当前的配色，深色模式也会同步。

### 构建
- Release 标签：`v1.0.8`
- 标签对应 Gradle 配置记录的 versionName 为 `1.0.6`、versionCode 为 `6`

— Lingion
