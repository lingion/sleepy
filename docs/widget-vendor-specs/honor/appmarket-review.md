# 荣耀应用市场上架与安全审核

来源: 荣耀开发者服务平台《应用审核FAQ》(100885)、《平台审核常见FAQ》(101269)、《App隐私常见问题及自检指南》(101581)。

## 审核时效与渠道

- 提交后 **1-3 个工作日**完成审核， 结果经开发者服务平台站内信、 邮件反馈。
- 一直审核中: 提供应用 AppID/应用名称/包名， 联系荣耀应用市场团队 `Developers_AppMarket@hihonor.com` 或提单 (三个工作日内答复)。
- 审核未通过按原因修改后重新上传。

## 包名规范 (官方原文)

1. 不得包含竞品平台缩写、 违禁敏感词等缩写；
2. 渠道包名与其他平台不一致时， **后缀添加 .honor 文案**。

## 版本审核核对项

APK 包 + 发布国家/地区 + 应用内资费 + 内容分级 + 隐私声明 + 版权信息 + 版号 + 开发者服务信息； 审核会进入应用内逐项判断与提交信息是否一致。

## 安全审核不通过情形 (官方原文)

1. 含有病毒； 2. 恶意吸费； 3. 获取多余设备权限威胁用户信息安全； 4. **自动开启后台服务**； 5. 涉黄、 涉暴、 涉政； 6. 影响设备性能； 7. 应用版权问题； 8. 影响用户行车安全。

注: "自动开启后台服务"为官方列名情形 — 后台自启类行为直接命中。

## 功能审核不通过情形 (官方原文)

1. 覆盖安装/安装/卸载失败； 2. 出现强制关闭； 3. 功能未实现； 4. 需求设计不合理； 5. **兼容性差**。

信息不符类: 安装后的图标/截图/名称/版本/功能与提交信息不符； 授权区域/描述语言/实际支持语言不匹配； 升级不满足条件； **应用截图含有竞品元素**。

## 广告审核不通过情形

纯广告应用； push 推送广告； 强制安装无关应用或插件； 链接或广告含第三方应用市场信息； 图标广告； 短信推送广告。

## 权限审核

- "索取多余用户权限"直接导致不通过: 读取通话记录、 通讯录、 短信记录、 获取手机号码、 通知栏推送广告等均被点名。
- 荣耀维护了权限逐项"使用及申请标准"清单 (短信/通话记录/设备管理器/剪贴板/文档/通讯录/日历/音频/图片视频/附近的设备/位置/通知/所有文件访问)， 提交前按清单自检。

## 隐私合规 (官方自检指南)

- 原则: 合法、 正当、 必要； 公开收集使用规则； 明示目的、 方式、 范围。
- App 收集行为与隐私政策声明必须逐项一致， 不超出声明范围。
- 个人信息类型必须点名具体 (Android ID、 ICCID、 IMEI、 IMSI、 MAC、 MEID、 OAID、 传感器、 位置、 WIFI 列表/SSID/BSSID、 剪切板、 软件列表、 硬件序列号、 通讯录、 系统账户、 通话记录、 音频、 IP 等)， 禁用"设备信息""标识符"这类模糊词。
- 第三方 SDK 的收集行为需逐项披露； 不清晰可向 SDK 方核实。
- **热更隐私政策后必须重新上传送检**， 否则不触发新检测任务。
- 未经用户同意读取个人信息 (如读设备序列号) 直接不通过。

## Widget 相关审核条款边界

官方 FAQ 未单列普通 AppWidget 审核条款。与小组件形态直接相关的官方验收要求落在荣耀智慧服务卡片测试指南 (见 launcher-behavior.md)： 网格全覆盖、 不空白、 兜底、 热区 32dp、 禁 toast、 直达落地页。不能把该指南扩大解释为所有 AppWidget 的市场审核规则； 普通 APK 仍按上述安全/功能/隐私条款审核 (见 gaps.md)。

## 其他渠道事实 (与本仓相关)

- 应用市场外分发: 荣耀提供"应用直投""自更新赋能""评论一键直达""应用市场跳转链接"等开发者能力 (101581 页目录)， APK 侧载之外的分发不只有应用市场一条路。
- 应用市场跳转链接: `astore.com` 域名示例出现在荣耀官方 intent-filter 文档样例 (Android 15 UriRelativeFilterGroup 示例)。
- 上架后默认授权: 荣耀开发者社区条款帖记录"应用在荣耀应用商店上架发布后， 默认授权荣耀应用商店为其在荣耀终端上 [分发]" (社区帖， evidence=B)。
