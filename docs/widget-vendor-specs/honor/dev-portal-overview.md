# 荣耀开发者服务平台总览 (与华为 HMS 的边界)

## 平台定位

荣耀开发者服务平台 (developer.honor.com) 是面向荣耀开发者的官方网站， 为应用开发者和设计人员提供荣耀 SDK 和文档， 站点描述为"构建全场景、 面向全渠道、 服务全人群"。域名另有 developer.hihonor.com 变体 (页内 favicon/跳转引用)。

## 分发服务清单

平台首页"高效的分发服务能力"栏目列出:

- 荣耀应用市场: 应用上架与分发。
- 荣耀智慧服务: 轻量化、 即点即用体验， 主动推荐 (即本目录 launcher-behavior.md 记录的卡片体系)。
- 荣耀主题: 全场景个性化换肤 (对应已有 theme-widget-user-guide.md)。
- 荣耀游戏中心: 官方游戏下载平台。
- 荣耀广告变现服务: 流量变现。
- 荣耀推送服务: 系统级推送 (对应华为 HMS Push 的荣耀对位能力)。

## 开放能力清单

首页开放能力分类: MagicRing、 Magic Live、 MagicGuard、 Turbo X、 Fitness、 Media、 System、 Device。基础服务清单:

- 推送服务: 高到达率、 安全稳定、 便捷集成。
- MDM 服务: 企业场景下系统级权限管理。
- 账号服务: 应用调用荣耀公开 API (对应华为 HMS Account 的荣耀对位能力)。
- 网络加速服务: 双向感知协同调度。
- 运动健康服务: 用户授权后的运动健康数据开放。
- 应用任务跨设备接续: 端端接续、 服务随人流转。

## 开发工具

- 云调试: 远程真机查看应用在不同机型上的运行表现。
- 云测试: 自动化兼容性、 稳定性打分体系。
- 主题制作工具: 可视化制作换肤内容 (文档在 kitId=11106)。

## 与华为 HMS 的区别 (事实边界)

荣耀开发者平台首页列出的服务 (账号、 推送、 应用市场、 MDM、 运动健康等) 均以荣耀自有品牌与自有平台入口呈现， 页面未声明这些服务与华为 HMS 是同一服务或互相兼容。荣耀设备判定使用 `Build.MANUFACTURER == "HONOR"`， 折叠屏特性判定使用 `com.hihonor.hardware.sensor.posture` system feature (见 android16-adaptation.md 通用适配指导引用)—— 系统 feature 命名空间是 `com.hihonor.*`, 不是华为的 `com.huawei.*`。

未发现荣耀官方发布的"荣耀服务 vs 华为 HMS"逐项差异表 (见 gaps.md)。可以确认的事实是: 荣耀提供独立账号体系、 独立应用市场审核通道和独立开放能力命名空间; 不能据此断言同一套 HMS SDK 可直接在 MagicOS 上工作。

## 登录/账号体系

平台采用荣耀账号体系 (首页"立即登录/注册")， 智能客服仅支持中国境内荣耀账号使用。文档聚合页覆盖账号注册、 实名认证、 应用开发、 能力集成、 上架分发与变现全流程。
