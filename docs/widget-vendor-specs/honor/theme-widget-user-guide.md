     荣耀主题小组件使用方法及支持的机型
  -- ------------------------------------
荣耀主题小组件样式丰富，满足用户装扮类、个性化的卡片需求。小组件可以配套不同主题或壁纸形成有趣的互动装饰，也可以进行自由布局，打造独一无二的个性桌面。
支持的机型
除荣耀平板及少数畅玩系列机型外，其他荣耀手机均可支持小组件功能。使用小组件功能前，请将荣耀主题APP升级到19.0.12或以上版本。
下载和添加小组件
可以通过以下任一方式，将小组件添加至桌面：（小组件添加过多可能造成设备卡顿等问题）
1.  进入荣耀主题APP>推荐>精选>小组件下载小组件，然后点击应用将其添加至桌面。
    []
2.  下载小组件后，双手捏合桌面>桌面卡片>下划找到并点击"经典小工具">下划找到主题>左右划动选择组件后，桌面会新增一个空白组件>填充>选择需要添加的小组件。
    a.  填充：点击填充，页面自动跳转到已经拥有的小组件页面，选择组件可添加至桌面。
    b.  复制：点击复制，可直接在桌面复制添加一个空白小组件，减少重复操作。
[][][][][]
移动/编辑/修改尺寸
添加小组件后，长按可进入编辑模式。在编辑模式，拖动小组件可改变小组件位置，拖动白色边框可改变小组件尺寸。
移除小组件
长按小组件 > 移除 > 移除，可移除小组件。
