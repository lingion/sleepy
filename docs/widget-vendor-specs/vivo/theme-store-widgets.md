# vivo 主题商店小组件 (妙玩组件) 与蓝河卡片、原子通知

> 定位: 与 Sleepy 无直接接入路径 (均为 vivo 生态独立通道),收作渠道边界事实。
> 妙玩组件是 i 主题内付费组件体系 (用户在 i 主题购买),与 OriginOS 桌面
> 原子组件 (开发者免费适配) 是两条不同通道。

## 妙玩组件 (i主题, doc 803-809)

### 通道定性

- 入口: 主题 (doc 520) → 妙玩组件 (803-809); 用户在 i 主题内购买/下载,
  非 Android AppWidget,非原子组件平台。
- doc 808: 各组件卡类型制作指导 v1.0 文档在**腾讯文档** (外部链接),
  附 vivo 定制【汉仪可变黑体】字体包下载链接。
- 定价档位 (doc 807): 免费 (2~10 个组件卡) / 3 元 / 4 元 / 更高档,
  按组件卡模版数量与风格质量分档。

### 资源包规范 (doc 806, 原文)

- **整个组件资源包总体积 ≤ 30M; 单组件卡资源包 ≤ 5M**。
- 预览图: png+gif, 2x2 = 432x432px, 4x2 = 924x432px, 4x4 = 924x924px;
  预览图体积 ≤ 1M。
- 深色模式: 资源支持深色模式需在简介增加一句"当前组件支持深色模式"。
- 版权: 所有资源需作品登记证书; 原创/非原创/IP 类各有证明材料要求;
  人物正脸需肖像权授权书。
- 禁止: vivo 品牌竞品题材、将 vivo 写为 "VIVO"、高耗电类资源、
  资源包内多余图片/文件。

### 效果引擎 (doc 801, 原文)

- vivo 效果引擎 = 一套通用图形渲染引擎,XML 描述语言,支持动态帧率
  (无动画时停止渲染,全速时最高 60 帧)。
- 资源包结构: ZIP → 3.0/1080P/xxx.itz → widget/widget_2x2_1/...
  (manifest.xml 布局配置 + var_config.xml 打卡编辑倒数日配置 + 图片素材
  image.png/image_dark.png + etc 字体)。
- 深色资源同名成对: `image.png` + `image_dark.png` (与原子组件同规)。
- 天气等数据组件有状态码体系: #weather_code 0=正常/1=未安装/2=未授权/
  3=未添加城市/4=无网络无缓存 — 异常状态需适配组件 view。
- Gif 支持: Image 增强功能支持 Gif 单次或循环播放,时长不超过 3 秒。

## 蓝河卡片 (BlueOS 手表, doc 937, 原文)

- 卡片 = 轻量应用形态,嵌入负一屏/桌面/全搜/锁屏/浏览器/语音助手等场景。
- 手表蓝河卡片: 固定尺寸 424x170px (#262626 底),圆角 R=40px,安全边距 22px。
- 字体: vivo Sans SC VF,标题 600 字重 38px #FFFFFF,辅助文本 500 字重 30px
  #9FA2A6; 最小字号 20px。
- 热区: 手表最小触控热区 7mm (约88px); 热区为规则矩形、大于等于可视元素、
  与中心对齐。
- 开发: 分标准卡和轻卡; 分发经蓝河应用审核规范 (698) + 蓝河应用上传发布 (891)。
- 与 Sleepy 关系: BlueOS 是 vivo 自研独立生态,Android APK 不可达。

## 原子通知 (doc 894/895, 原文)

- 定位: 通过场景细分和可视化的通知形态 (外卖进度/打车进度类实时事件),
  显示在熄屏、锁屏、状态栏、通知中心、桌面组件 (小卡) 上。
- 原子岛机型状态栏显示"原子岛胶囊"; 非原子岛机型显示"普通胶囊"。
- 接入: 应用已在 vivo 应用商店上架 + 邮件 oosyztz@vivo.com 申请准入
  (7-10 个工作日) → 需求定义及 UI 设计 → 双方评审 → 开发联调 → 上线
  (机型逐步放量) → 定期体验巡检。
- 禁止准入: 广告营销/引导下载/引流曝光、违法违规信息、隐私信息 (需脱敏)。
- 与 Sleepy 关系: 通知型场景组件,Android 通知体系外的 vivo 专属通道;
  Sleepy 课表提醒走标准通知 + 本地通知分类备案 (doc 930) 即可,无需原子通知。

## 通道边界总结 (vivo 五条 widget 相关通道)

| 通道 | 载体 | Sleepy 可达性 |
|---|---|---|
| 标准 AppWidget | Android RemoteViews | 可达 (默认通道) |
| 原子组件 | AppWidget + meta-data + 组件平台审核 | 需上架 vivo 商店 + 平台准入邮件 (oosyzzj@vivo.com) |
| 妙玩组件 | i 主题效果引擎 .itz 包 | 不可达 (i 主题付费生态,主题商店资质) |
| 蓝河卡片 | BlueOS 手表 | 不可达 (独立 OS) |
| 原子通知 | vivo 专属通知形态 | 需上架 + 准入邮件 (oosyztz@vivo.com),非 AppWidget |
