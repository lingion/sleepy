# 魅族 Flyme — 深色模式跟随行为

> 与 samsung/darkmode-behavior.md 对应的魅族侧文档。魅族无深色模式开发者规范页 (开放平台文档树无此主题), 本文件为消费者行为层面的官方事实。

## 一、深色模式启用方式 (docId 254, 官方)

3 种启用方式 (原文):
1. **手动启动**: 「设置 > 显示和亮度」中, 或控制中心快捷按钮。
2. **定时切换 — 日落到日出**: 系统自动根据时钟和地理位置数据确定夜晚时间并开启。
3. **定时切换 — 自定义时段**: 在特定时段自动开启。

## 二、深色模式设置项 (docId 254, 官方)

- **色调**: 「默认」或「柔和」二选 — Flyme 深色有两档色调, 非 Android 标准 pure dark。
- **调暗壁纸**: 开启后降低亮色壁纸亮度, 提升屏幕舒适度。
- **深色应用管理**: 「进入"深色应用管理"可手动开启/关闭部分 (未自动适配) 第三方应用的深色模式」— 关键条款:
  - Flyme 会识别未自动适配深色的第三方 App 并提供系统级强制染色通道。
  - 用户可逐应用开关; 被强制染色的 App 的界面 (含可能的 widget 渲染层) 由系统调色处理。
  - AppWidget 渲染结果被系统调色的具体行为无官方文档描述, **不做断言**; 唯一确定事实 = 通道存在且用户可控。

## 三、AppWidget 深色适配的魅族侧事实

- **魅族无 AppWidget 深色适配的官方规范** (对比小米: 「深色模式必须适配」是小米小部件审核硬条款, dev.mi.com qa-faq)。
- 小米 QA 揭示的机制 (新版本宿主缓存 RemoteViews, 深色切换用上一次的 RemoteViews 重建 widget, 要求 xml 静态适配深色、不支持代码动态切换) 在 Flyme 上**未验证, 不外推** — 魅族是否有同款宿主缓存机制无公开资料。
- Sleepy 对策: 全部变体的深色适配走静态资源 (values-night / RemoteViews 布局内颜色资源引用), 与小米约束同构的保守做法在魅族上无害; 不使用代码级深色切换。
- Flyme 12.6 官方修复记录含「修复深色模式下微信界面显示异常的问题」(firmwarelist-198, 2026-06-30) — 深色模式对三方 App 适配是 Flyme 持续修补面, 三方 App 深色异常在 Flyme 上有真实发生率。

## 四、屏幕显示相关配套 (docId 254, 官方)

- 屏幕色彩模式: 自适应/标准/鲜艳 3 档 + 色温横轴手动调节 — 色温偏移会影响 widget 颜色观感, 无厂商锁定。
- 刷新率: 144/120/90/60Hz; 分辨率: QHD+ (3200x1440, 3192x1368) / FHD+ (2400x1080, 2128x912)。
- **显示和字体大小可调**; 「超大字体简易模式」下系统用更大字体图标, 导航自动切安卓导航栏, 桌面提供手电筒和一键拨号 — AppWidget 内固定 dp 布局需容忍 fontScale 放大 (跨厂商通用遮挡风险, 荣耀 #31 实锤同款)。
- 系统字体大小修改时桌面应用名称大小跟随修改 (Flyme 10.5 官方更新记录) — 桌面层字号随动, widget 内字号不随系统字号自动缩放 (RemoteViews 机制), 遮挡风险与跨厂商一致。

## 五、与 samsung/darkmode-behavior.md 的对比 (仅事实差异)

| 维度 | 三星 One UI | 魅族 Flyme |
|---|---|---|
| 深色模式开发者规范 | 有 (color/theme.html, 对比度/双值色/双模式测试要求) | 无 (消费者文档层面) |
| 双模式测试要求 | 发布前必须 (官方原文) | 无官方要求 |
| 强制染色通道 | One UI 8.5 起推进图标深色适配 (社区报道) | 「深色应用管理」用户可控逐应用开关 (官方) |
| AppWidget 深色适配 | 无商店审核条款 | 无审核 (未上架商店) |
| 色值 token | 官方给出 #0072de / #3e91ff 双值 | 无官方 token |

## 落点 (仅事实归纳)

1. Flyme 深色模式 = 消费者行为层, 无开发者规范; 静态资源适配深色是全厂商保守做法, 在魅族上无害且必要。
2. 「深色应用管理」强制染色通道存在 (官方), 用户可控; widget 深色适配不佳时用户有手动开启通道。
3. fontScale 放大 + 超大字体简易模式是 Flyme 上 widget 遮挡的真实风险面, 与荣耀 #31 同构。
