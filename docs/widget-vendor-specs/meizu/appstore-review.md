# 魅族应用商店上架要求 (审核规范 / 发布流程)

> 魅族开放平台官方审核规范全文要点。与 samsung/galaxystore-review.md 对应的魅族侧文档。

## 一、审核流程 (docId 27, 官方)

- 审核链路 = **安全扫描 + 兼容性测试 + 人工审核**, 共 1-3 个工作日 (周末节假日不算)。
- 安全扫描未过: 用 360 等安全软件扫描复现, 误报可反馈; 兼容性未过: 反馈后台 Log 给开发排查; 人工未过: 按审核规范整改; 有疑问发 [应用名称+包名+问题说明] 至 dev@xjmz.com。
- 审核状态机: 草稿 / 审核中 / 预上架 / 上架 / 下架 / 审核不通过 / 下架申请中。
- 超期催审: 1-3 个工作日未过可发邮件 dev@xjmz.com (附包名)。

## 二、应用信息条款 (docId 110 第一章)

- **名称**: ≤10 中文字符或 20 英文字符 (含副标题); 禁 @#￥%&* 等特殊字符; 禁政治敏感/色情/暴力/恐怖内容; **不得以日历、桌面、视频、贷款、赚钱、小说等泛词、功能词、类别词命名**; 禁与已上架应用重复混淆; 禁与安装到设备上显示的名称差异较大; **禁未经授权使用魅族或 Flyme 元素**; **禁与 Flyme 内置系统应用重名**; 禁堆砌关键词等恶意 ASO。
- **图标**: 与安装到设备上显示的一致; 禁拉伸/压缩/模糊/黑(白)边/黑(白)角; 禁真人美女头像 (明星代言除外); 禁擅自有奖/首发/精品/官方/正版/推荐/HOT 标签。
- **截图和启动页**: 禁与实际功能无关内容; 禁重复/拉伸/压缩/模糊; **禁第三方应用商店 logo**; **禁其他品牌手机外观素材, 推荐魅族手机外观素材** (官方提供下载地址)。
- **描述和关键词**: 仅限中文与英文; 篇幅 100-1000 字符且与功能一致; 禁极限词 (最/第一/唯一/NO.1/必备/免费送/全球/顶尖/首); 关键字空格隔开; **描述及更新日志中不得出现第三方应用商店名称/介绍/引述**。

## 三、应用安全条款 (docId 110 第二章)

- 禁病毒木马; 禁恶意吸费 (未经用户二次确认的主动扣费/隐形扣费); 禁屏蔽用户正常通信; 禁未经授权强制启动系统服务; 禁获取无关权限; **禁第三方加载可执行代码的应用或 SDK**; 禁未经允许发短信/打电话; 禁未告知频繁自动联网。

## 四、应用功能条款 (docId 110 第三章 — 与小组件相关的硬条款)

- **应用需适配魅族主流终端设备和 Android 版本**。
- 应用需能正常安装/启动/卸载, 不得频繁崩溃或需第三方软件才可卸载。
- **安装后仅允许在桌面生成一个快捷图标** (禁图标快捷方式捆绑)。
- **不得出现无法关闭的常驻通知栏** (常驻通知必须有关闭途径)。
- 功能需已实现且使用正常, 禁按钮点击无反应或报错。
- 仅限部分城市/人群使用的功能需在描述中注明。
- 禁影响终端设备功能 (自动修改系统默认配置且用户无法修改/功能键失灵)。
- 禁对其他应用恶意干扰/屏蔽/修改数据; 禁强制开机启动; 禁静默或强制要求下载其他应用; 禁隐藏功能; 禁 root; 主要功能禁单一广告或积分墙。

## 五、应用内容条款 (docId 110 第四章)

- 禁以分发为主要目的 (应用商店/游戏中心); 禁简单打包网站页面/套模板/罗列链接; 禁与已上架应用相同或高度相似; 禁破解版/汉化版/重新打包盗用; 禁网络正常时无法获取内容或大量测试数据。
- **不接受将应用内某一内容独立作为新应用上传 (影视剧集/图书单行本/单一主题/单一游戏攻略/单一壁纸/单一锁屏/单一旅游攻略等)** — 单一内容拆分上架禁令。
- UGC 须有效管控 (过滤机制 + 举报机制及时响应 + 服务关闭功能)。

## 六、应用内广告条款 (docId 110 第五章 — 与桌面相关的硬条款)

- **广告面积不得超过手机屏幕的 50%**, 且不得包含空白广告位。
- **禁止应用存在通知栏广告**。
- **禁止应用劫持系统桌面或者锁屏**。
- **禁止应用在桌面上添加以广告为目的图标**。
- **禁止使用过程中频繁弹出悬浮窗广告, 中断用户操作**。
- 禁插屏广告代码/积分墙广告代码/风险代码; 广告需带关闭功能且关闭后广告同时关闭; 禁匿名推送; 禁其他应用商店相关推广。

## 七、用户隐私条款 (docId 110 第六章)

- **应用内应含有单独成文的隐私政策**; **单机工具类应用的隐私政策需在无网络的情况下正常阅读**。
- 隐私政策标题格式: 「隐私声明」「个人信息保护声明」「用户隐私声明」等; **不得使用「用户协议」「用户说明」「服务协议」等**。
- 使用中主动提醒阅读 (首次进入/注册/弹窗/文本链接/FAQ 等)。
- 必含运营者基本信息: 公司名称 (需与账户主体一致)、注册地址、常用办公地址、信息保护负责人联系电话。
- 需列举业务逻辑与权限的关系; 说明获取个人隐私信息的用途; 禁与功能无关的敏感权限; 禁未授权私自收集/传输/使用隐私数据。

## 八、暂不收录的应用类型 (docId 110 第七章)

- **单一壁纸、主题、锁屏类应用 (请通过"我的主题"发布)** — 与 AppWidget 应用相关的边界: 纯壁纸/主题/锁屏工具不收录。
- 游戏类走"我的游戏"; **平板应用**; 支持手游充值; 自动抢红包; 主要功能需 root; 主要功能需付费; 伪装本机电话号码/通话声音; 诱导分享赚收益; 积分墙 WiFi 破解; 非官方游戏攻略/社区; 赌博/非法金钱交易; 网赚; **含应用分发属性 (支持下载、搜索和更新应用功能)**; **政治敏感内容及相关辅助工具 (VPN、翻墙、反动、境外媒体、加速器等)**; 彩票相关; 社交对话生成器; 竞拍夺宝; 需读通讯信息的网贷; 游戏外挂; 模板打包应用。

## 九、发布与管理流程 (docId 14, 官方)

- 入口: 服务 > 流量分发 > 应用服务 > 上传应用 → 应用管理页。
- 提交: 上传 APK 解析 → 填必填项 (名称/描述/版本描述/关键词/发布者/图标/截图/分类/资质) → 完成并提交审核。
- 维护: 同版本更新 (小 Bug, 上架版本专用); 版本回滚 (邮件申请); 换签名 (申请重置); 应用认领; **暂不支持删除应用** (只能下架, docId 19 流程)。
- 快应用: 走快应用联盟 quickapp.cn 注册 + 绑定魅族, 与 APK 上架是两条线。

## 十、APP 备案前置 (docId 210, 官方)

- 工信部 APP 备案为上架前置: 2023-09-01 起新增应用须备案后上架; 2023-12-12 起限制未备案应用版本更新; 2023-12-27 起逐步清理在架未备案存量应用。
- 平台上传的包名、证件号须与工信部备案系统一致; 备案编号须在 APP「设置」两级菜单以内标注并链接 https://beian.miit.gov.cn。

## 十一、年龄分级 (docId 169, 官方)

- 5 级: 3+ / 7+ / 12+ / 16+ / 18+; 3+ 禁暴力惊吓粗俗; 12+ 允许虚构角色暴力但禁强诱导性 (氪金、骚扰); 16+ 允许少量暴力强刺激性言语禁性暗示; 18+ 禁激烈暴力/色情/虚拟赌博/吸毒。

## 与 Sleepy 的落点 (仅事实归纳)

1. 若未来上架魅族商店: 纯工具类 AppWidget 应用 (无广告/无推送/无自更新/无分发功能) 天然满足大部分条款。
2. 隐私政策必须单独成文且标题用「隐私声明」类格式, 单机工具类断网可读 — Sleepy「我的 → 关于」页的隐私声明需按此格式核对。
3. 「安装后仅允许生成一个快捷图标」「常驻通知栏必须有关闭途径」与 widget 无冲突。
4. 备案编号标注位置 (设置两级菜单内 + 链接工信部) 是上架前置。
5. Flyme 图标重绘通道 (docId 27): 商店为优质应用重绘 Flyme 风格 Icon, 应用可申请; 用户可在系统设置关闭恢复原始图标。
