# Sleepy v1.0.40

### Send feedback from About
About now offers GitHub Issue and email feedback with app version, Android version, device model, resolution, and language prefilled. Timetables, files, and account credentials are not attached.

### Open timetable files from a file manager
Opening `.json`, `.ics`, `.html`, `.csv`, or `.xml` files can now offer Sleepy directly as an app.

### Update notes render as formatted text
The update dialog now renders headings, lists, and bold text instead of showing raw Markdown. Mirror-based update checks also include the release notes.

### Build
- Release tag: `v1.0.40`
- versionCode: `41`

# Sleepy v1.0.40

### 关于页可以反馈问题
关于页现在支持 GitHub Issue 和邮件反馈，并会预填应用版本、Android 版本、设备型号、分辨率和语言。不会附带课表、文件或账号信息。

### 文件管理器可以直接打开课表文件
在文件管理器中打开 `.json`、`.ics`、`.html`、`.csv` 或 `.xml` 文件时，现在可以选择 Sleepy。

### 更新说明按格式显示
更新弹窗现在会正确显示标题、列表和加粗文字，不再直接显示 Markdown 源码；通过镜像检查更新时也会包含更新说明。

### 构建
- Release 标签：`v1.0.40`
- versionCode：`41`

— Lingion
