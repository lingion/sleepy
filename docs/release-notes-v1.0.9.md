# Sleepy v1.0.9

### The grid widget no longer fails to render
Before, the 5×5 grid widget could show “cannot show content”. Its layout has been rewritten to match the in-app grid, including day headers, a time column, multi-period course cards, and a highlighted current day.

### The interface is available in five languages
Before, much of the interface was fixed in Chinese. The app now provides Simplified Chinese, Traditional Chinese, English, Japanese, and Spanish resources, following the device language.

### Build
- Release tag: `v1.0.9`
- Debug APK: `Sleepy-v1.0.9-grid-fix.apk`
- Application ID: `com.lingion.sleepy.debug`

— Lingion

# Sleepy v1.0.9

### 网格小组件不再无法显示
之前，5×5 网格小组件可能显示 “cannot show content”。现在已重写布局，使它与 App 内网格视图一致，包含日期表头、时间列、多节课程卡片和当前日期高亮。

### 界面支持五种语言
之前，界面中有大量中文写死。现在提供简体中文、繁体中文、英语、日语和西班牙语资源，会跟随设备语言。

### 构建
- Release 标签：`v1.0.9`
- Debug APK：`Sleepy-v1.0.9-grid-fix.apk`
- Application ID：`com.lingion.sleepy.debug`

— Lingion
