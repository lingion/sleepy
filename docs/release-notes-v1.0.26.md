# Sleepy v1.0.26

### Check and install updates from About
The About page can now check for a newer release, select the APK matching the device ABI, download it, and hand installation to Android. A mirror is used when the primary host is unavailable.

### HEU imports use the selected semester
Before, the Wisedu API could return a stale semester list. The importer now reads the semester shown by the page. The import confirmation also accepts a timetable name and adds a suffix when that name already exists.

### Build

# Sleepy v1.0.26

### 关于页可以检查并安装更新
现在可以在关于页检查新版本，按设备架构选择 APK，下载后交给 Android 系统安装。主地址不可用时会使用镜像。

### 哈工程导入使用页面选中的学期
之前，Wisedu 接口可能返回过期的学期列表。现在会读取页面实际显示的学期。导入确认页也支持填写课表名称，同名时自动添加后缀。

### 构建
- Release 标签：`v1.0.26`
