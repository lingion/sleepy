# Sleepy v1.0.16

### The first timetable is no longer hidden
Before, an empty installation could create a hidden placeholder timetable and keep showing it after you created your own. The first timetable you create is now the default, and the app distinguishes between no timetables and a timetable with no courses.

### Periods can be generated automatically
The period editor now has Manual and Automatic tabs. Set period length, daily period count, and break transitions; Sleepy calculates the day and updates a preview as you edit. Zero-minute gaps remain valid.

### The Automatic tab no longer crashes
The crash shipped in the first v1.0.16 build has been fixed.

### Build
- Release tag: `v1.0.16`
- APK: 20.4 MB
- versionCode: `16`
- Tests: `37` passed

# Sleepy v1.0.16

### 第一张课表不再被隐藏
之前，空应用会偷偷创建占位课表，创建自己的课表后仍然指向那张看不见的表。现在你创建的第一张课表就是默认课表，并分别处理“没有课表”和“课表为空”两种状态。

### 节次支持自动生成
节次编辑器现在分为手动和自动两个 Tab。填写每节课时长、每天节数和课间位置后，Sleepy 会计算全天节次，修改时同步更新预览。零分钟间隔仍然有效。

### 自动 Tab 不再崩溃
v1.0.16 首个构建中点击自动 Tab 会崩溃的问题已经修复。

### 构建
- Release 标签：`v1.0.16`
- APK：20.4 MB
- versionCode：`16`
- 测试：`37` 项通过
