# Sleepy v1.0.19

### Swipe between weeks
Before, changing weeks required the arrows or the week picker. Week View and Grid View now support horizontal swipes, while the arrows and picker stay synchronized.

### Creating a timetable waits for Save
Before, a new timetable was written immediately. It now becomes active only after you confirm Save, and the Manage page no longer jumps while it is being created.

### Import opens as a bottom sheet
Timetable import now opens from the bottom instead of taking over the whole screen.

# Sleepy v1.0.19

### 左右滑动切换周次
之前只能用箭头或周次选择器切换。现在周视图和网格视图都支持左右滑动，箭头与选择器也会保持同步。

### 新建课表点击保存后才生效
之前，新课表会立即写入。现在确认保存后才会生效，管理页创建过程中也不再跳动。

### 导入改为底部弹窗
导入课表现在从底部弹出，不再占满整个页面。

- Release 标签：`v1.0.19`
