# Sleepy v1.0.41

### Excel web exports fail with a useful explanation
Before, importing Excel's “Save as Web Page” shell failed without saying why. Sleepy now recognizes the frameset, identifies the adjacent sheet file, and asks you to save the timetable as CSV or a normal web page instead of a single-file web page.

### Release notes render correctly on the device
The update dialog now renders headings, indented bullet lists, bold text, inline code, and links itself. Unknown or malformed markup falls back to text, and long notes can scroll.

- versionCode: `42`

# Sleepy v1.0.41

### Excel 网页导出失败时会说明原因
之前导入 Excel“另存为网页”的壳文件时会直接失败。现在 Sleepy 会识别这种 frameset，指出旁边的课表文件，并提示改存为 CSV 或普通网页，不要使用单个文件网页格式。

### 更新说明在真机上正常排版
更新弹窗现在由 App 自己渲染标题、缩进列表、粗体、行内代码和链接。未知或格式错误的标记会回退为普通文字，较长的说明可以滚动。

### 构建
- Release 标签：`v1.0.41`
- versionCode：`42`
