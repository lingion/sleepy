# Sleepy v1.0.3

### Import now has a confirmation step
Before, importing a timetable wrote it immediately, without checking the semester start date or period times. Sleepy now shows those values before saving, so they can be corrected before the timetable is written.

### Courses can be edited after import
Before, changing an imported course meant deleting it and creating it again. Tapping a course now opens its edit screen.

### Build
- versionName in the tagged build: `1.0.0`
- versionCode: `1`

# Sleepy v1.0.3

### 导入前先确认课表配置
之前，导入课表会立即写入，学期开始日期和每节课的时间也没有确认机会。现在导入前会显示这些信息，可以先修正，再确认保存。

### 导入后的课程可以直接编辑
之前，想改导入后的课程只能删除后重新创建。现在点击课程即可进入编辑页面。

### 构建
- 标签对应构建的 versionName：`1.0.0`
- versionCode：`1`
