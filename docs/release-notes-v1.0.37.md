# Sleepy v1.0.37

### Grey out courses on holidays and weekends
You can now configure public-holiday and weekend dimming, choose the dimming style, ignore make-up workdays, edit date ranges, add local holidays, and restore deleted ranges. Holiday data is cached locally and can be refreshed. Widgets follow the same dimming state.

### Today courses open their details
Courses in the Today card can now be tapped to view and edit their details.

### Convert timetable text with a prompt
The plain-text import screen now provides a prompt for converting a timetable with an AI tool. Returned period times and common line layouts are accepted by the importer.

### Semester boundaries are respected
Before or after the configured semester, the schedule, Today page, widgets, summary, Fluid Cloud, and alarms no longer show or announce courses outside the term.

### Import setup and surfaces are clearer
The semester start date uses a calendar picker, confirmed imports return to the schedule, and default outlines were removed from selectors, chips, and theme cards.

- versionName: `1.0.37`
- versionCode: `38`
- ABI APKs: `app-arm64-v8a-release.apk`, `app-armeabi-v7a-release.apk`, `app-x86_64-release.apk`

# Sleepy v1.0.37

### 节假日和周末课程支持灰显
现在可以配置法定节假日和周末灰显、选择灰显样式、忽略补班日，编辑日期范围，添加本地节假日并恢复已删除范围。节假日数据会缓存在本地，也可以手动刷新；小组件会同步灰显状态。

### 今日课程可以打开详情
现在可以点击今日卡片中的课程查看和编辑详情。

### 可以用提示词转换课表文本
纯文本导入页现在提供转换提示词，供 AI 工具生成可导入课表。回复中的作息时间和常见行格式也会被识别。

### 学期边界统一生效
配置学期开始前或结束后，课表、今日页、小组件、摘要、流体云和提醒不会再显示或播报学期外课程。

### 导入配置和界面更清楚
学期开始日期改用日历选择器，确认导入后直接回到课表；选择器、芯片和主题卡移除了默认描边。
