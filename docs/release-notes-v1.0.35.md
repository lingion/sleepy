# Sleepy v1.0.35

### Choose the information below a grid course name
Grid cards can now show the room, the teacher, or no secondary information. A missing room or teacher leaves no blank line, and changes apply immediately.

### Import and preview screens follow the selected theme
Before, the JW import page, WeekGrid preview, and conflict card could use the default purple or fixed error colors. They now follow the in-app theme and light/dark choice.

### Course cards separate the title and secondary line
When secondary information is shown, the course name is centered in the upper area and the room or teacher is placed at the bottom. Cards without secondary information remain centered.

### Appearance and General settings are separated
Appearance now focuses on theme colors. Course-display and widget settings live under General, and display changes continue to refresh widgets immediately.

### Build
- Release tag: `v1.0.35`
- versionName: `1.0.35`
- versionCode: `36`
- ABI APKs: `app-arm64-v8a-release.apk`, `app-armeabi-v7a-release.apk`, `app-x86_64-release.apk`

# Sleepy v1.0.35

### 网格课程名下可以选择副信息
网格卡片现在可以在课程名下显示教室、教师或不显示副信息。教室或教师为空时不会留下空行，修改立即生效。

### 导入和预览页面跟随所选主题
之前，教务导入页、周网格预览和冲突卡可能使用默认紫色或写死的错误颜色。现在会跟随 App 内选择的主题和明暗模式。

### 课程卡片重新安排标题和副信息
显示副信息时，课程名会在上半区居中，教室或教师贴在卡片底部；没有副信息的卡片仍保持整体居中。

### 外观和通用设置分开
外观页现在专注于主题颜色，课程显示和小组件设置移到通用设置；显示设置修改后仍会立即刷新小组件。

### 构建
- Release 标签：`v1.0.35`
- versionName：`1.0.35`
- versionCode：`36`
- ABI APK：`app-arm64-v8a-release.apk`、`app-armeabi-v7a-release.apk`、`app-x86_64-release.apk`
