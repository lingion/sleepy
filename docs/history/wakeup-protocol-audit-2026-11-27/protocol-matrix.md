# 教务协议鲁棒性矩阵

本矩阵记录本轮审计后的代码契约。协议字段本身仍遵循各学校页面的数据结构，脚本局部变量名不作为协议条件。

| 协议族 | 数据证据 | 改名和容器变化处理 | 边界处理 | 当前结论 |
|---|---|---|---|---|
| 经典 EAMS | TaskActivity 参数、实际 activities[slot] 写入、坐标公式、marshalTable | 使用 Unicode JavaScript 标识符和成员路径。表格接收者、槽位绑定和脚本收尾按实际引用读取 | 收尾调用之后的表单或菜单数字不再进入任务坐标。公式形态支持改名后的步长和槽位 | 已增强 |
| 经典 EAMS 裸线性坐标 | index = 42 一类旧片段 | 保留旧兼容路径，依赖页面声明的 unitCount 或旧的 index 形态 | 没有公式、数组写入或可验证步长时，静态文本无法唯一推导每天节数 | 保留并记录限制 |
| ECUPL 年表 | TaskActivity、坐标写入、实际 marshalTable | 使用成员路径和实际接收者，不使用 table0 等固定名称 | 只读取活动所属表格和有效时间矩阵 | 已增强 |
| ECUPL 脚本表 | CourseTable、八参数 newActivity、对应 addActivityByTime | 绑定来自实际赋值或任意 var、let、const 声明。未发现绑定时拒绝猜测 | 不同脚本不互相借用活动绑定，时间矩阵和周次仍需完整 | 已增强 |
| 旧树维 shuwei_old | 五、七、十一参数 TaskActivity、活动数组写入和表格收尾 | 活动接收者、数组接收者和 marshalTable 接收者允许改名。置信度不再写死 activity 与 table0 | 保留旧最小采集片段的名称兼容分支，收尾后的坐标不参与 | 已增强 |
| 清华脚本 | 实际课程详情缓冲和实际坐标绑定 | 缓冲变量、成员路径和 Unicode 标识符均由共享脚本层解析 | 多次写入、无关缓冲、注释和字符串假数据隔离 | 已增强 |
| 正方、URP 和 JSON 脚本 | 完整课程字段结构、数组对象和日期或周次字段 | 依据对象字段和完整课程行选择候选，不依赖装饰容器名称 | 坏行局部跳过，多个不同布局拒绝拼接 | 已增强 |
| 研究生 HTML 表格 | 表格网格、星期表头、物理节次、课程字段 | 候选表按结构选择，装饰表和容器名称变化不改变选择 | 相同布局只取一次，不同候选不猜选 | 已增强 |
| 自动选帧和登录态 | 可访问 frame 的真实课程结构和登录失效指纹 | 选帧复用注册解析器的结构判定 | 全部可达帧登录失效时拒绝使用缓存课表 | 已审计 |

## 共享静态解析层

JwScriptSource、JwScriptMask 和 JwScriptJson 共同提供以下能力。

- Unicode 标识符和成员路径识别。
- 注释、字符串、模板字符串和正则字面量遮罩。
- 静态字符串拼接、别名快照和成员绑定解析。
- JSON 课程结构候选识别。
- 嵌套深度和静态展开量限制。

这些能力只读取静态页面内容，不执行页面脚本。
