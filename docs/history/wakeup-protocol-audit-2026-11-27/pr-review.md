## PR 链的共同结论

这些 PR 的共同变化是从固定页面名字转向真实数据结构。变量名、声明关键字、成员路径中的空白、装饰表和页面标题都不应单独决定导入结果。课程字段、坐标关系、周次位图、物理节次和活动写入接收者仍然需要形成可验证结构。

本轮继续收紧了几处遗漏点。经典 EAMS 的任务扫描在 marshalTable 收尾处停止。ECUPL 不再用默认 activity 猜绑定，年表作息参数必须来自接收活动的表对象，并允许合法跨脚本绑定和成员点号空白。旧树维的置信度改为识别实际 TaskActivity、活动数组或表格收尾结构，多候选标题累加器不会覆盖明确课程名。
