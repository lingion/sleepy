# Code state

`JwScauParser` routes Element UI before the two WakeUp border-grid shapes. It keeps original cell positions, skips header rows when numbering border-grid course rows, parses parity only from week text, and preserves gaps in week lists. `JwParserRegistry` registers `TYPE_SCAU` for import. Tests exercise the pinned Element UI layout, positive border-grid fixtures, and negative cases for missing weeks, skipped columns, headers, and the word `单片机`.

Production directory currently declares SCAU as `qz` at `http://jwxtxs.scau.edu.cn/default2.aspx`; this PR does not change the advertised login URL without a live account. The pinned Element UI test goes through `JwImportViewModel.parseHtmlStatic` using the actual directory JSON type and the legacy URL-detected type to check actual fallback routing rather than registration alone. The importer narrowly redirects QZ/ZF/ZF_1 only when the source contains a structurally valid, nonempty Element UI course table; unrelated grid HTML stays on its declared parser. Generic WebView frame capture already recognizes `el-table__body`; these tests verify captured HTML import, not live login or portal availability.
