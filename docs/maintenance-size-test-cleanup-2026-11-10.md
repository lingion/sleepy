# Sleepy 测试与安装包精简记录

本次工作以 Android 提交 `77b878fd5c8903a3f201ea938b3b152de4c4fbc0` 和 sleepy-site 提交 `256f42194592656b93b64c7e1e19240ae9c2f5ea` 为固定基线。全程使用一个执行链，没有并行代理、并行构建或并行测试。

## 验收条件

1. 清理只验证源码写法、重复实现或废弃界面的测试，保留调用生产逻辑的有效覆盖，并实际运行完整单测。
2. 构建前后同源、同签名方式的 Release APK，比较体积，验证目录数据和第三方原文完整性。
3. sleepy-site 承接完整开源页，应用提供浏览器入口；验证中英文页面、窄屏布局及许可原文链接。

## 测试和贡献流程

JVM 测试声明从 4,699 项减至 4,071 项，净删除 628 项，删除 88 个 JVM 测试文件。逐文件清理记录见同目录的 `maintenance-test-cleanup-2026-11-10.json`。另外移除 12 项锁定旧版本和文案的 Python 文档测试，以及对应 CI 步骤。

删除的代表包括读取 `.kt` 后匹配函数名、注释和动画参数的测试，复制业务判断后只测副本的测试，以及强制两套目录存储相同 PNG 的测试。混合文件中的真实行为测试继续保留，清理后也移除了它们不再使用的源码读取助手。

保留学校解析 fixture、实际采集脚本执行、数据库和撤回、导入导出、Compose 手势、像素渲染、组件声明及既有用户布局顺序契约。开发者先运行相关行为测试，完整检查继续由 CI 执行。学校目录测试资源改由 Gradle 自动生成，删除了 44,984 行的手动副本。

## 安装包与数据

14 张组件预览图从两套相同 PNG 改为单套无损 WebP，文件总和从 2,049,904 字节降至 340,452 字节。转换保留 RGBA，已逐张比较全部像素。

Release 开启资源裁剪，收紧 Serialization 和 WorkManager 的全包保留规则，保留反射构造器及序列化、Room、组件入口。移除源码和资源均未使用的 Coil、三项自适应布局依赖及 JUnit 参数化依赖。Room schema 只作为测试资产，继续保留在仓库供迁移审查。

构建时生成运行时 JSON，学校目录只压缩空白；城市文件只包含 `SchoolCityIndex.parse` 实际读取的 `schools` 映射，完整研究证据仍保留在源码。城市文件从 3,106,552 字节降至 165,677 字节，学校目录从 1,199,050 字节降至 953,979 字节。

## 开源页迁移

应用关于页的开源声明入口打开 `https://sleepy.is-my.app/licenses/`。保留旧版保存的 License 路由类型，恢复旧导航状态时显示关于页，避免序列化恢复失败。

网站承接 192 项来源、7 位贡献者、17 组跨校参考、51 组学校致谢，以及原来的六语言完整声明。许可原文继续随应用分发，并可从官网读取。历史链接的未确认状态继续显示。原始历史数据保存在 `docs/attribution-audit/legacy-credits.json`。

页面位置和顺序如下：

```text
应用关于页
  开源声明链接

官网开源页
  页面标题与区块导航
  许可证及声明原文
  贡献者
  当前来源与研究参考
  历史跨校参考、学校致谢、完整声明
  页脚及语言切换
```

维护来源清单后，在 Android 仓库依次执行：

```sh
python3 scripts/generate_attributions.py
python3 scripts/export_licenses.py --site /path/to/sleepy-site
python3 scripts/generate_attributions.py --check
python3 scripts/export_licenses.py --site /path/to/sleepy-site --check
```

网站的中文页面为 `/licenses/`，英文页面为 `/en/licenses/`。先部署网站，再发布带新入口的应用。初次检查仅准备源码。后续按用户部署指令，官网许可迁移 PR48 和 Material 打磨 PR50 已合并；生产部署 732f8e9bd24ab0a882c4fc15885628360857cea7 于2026年11月10日11:21 UTC成功。

## 实测体积和解析速度

相同固定基线、相同本地签名方式的 Release 构建比较如下。这里的 MB 为十进制百万字节，不是线上正式签名的新版本。

| APK | 基线 | 优化后 | 减少 |
| --- | ---: | ---: | ---: |
| arm64-v8a | 9.720 MB | 6.710 MB | 30.96% |
| armeabi-v7a | 9.715 MB | 6.706 MB | 30.98% |
| universal | 9.816 MB | 6.806 MB | 30.66% |
| x86_64 | 9.717 MB | 6.707 MB | 30.97% |

arm64 共减少 3,009,582 字节。ZIP 压缩后的资源从 2,857,943 字节降到 849,490 字节，资产从 3,146,007 字节降到 2,408,774 字节，DEX 从 3,488,808 字节降到 3,281,456 字节。四个 APK 均通过 ZIP CRC、学校数据相等、城市映射相等、全部 14 张预览保留及许可原文 SHA-256 检查，生产 APK 不再包含 Room schema。

调用真实 `SchoolCityIndex.parse`，先核对结果相等，进行 12 组预热，再交替顺序测量 50 组。本机 JVM 中位耗时从 72.38 ms 降到 6.39 ms，P90 从 82.83 ms 降到 8.14 ms。该结果仅代表城市索引解析，不代表 Android 整机启动耗时。

## 采集器与网站的补充清理

Go 测试函数从 44 个减至 39 个。删除普通测试中下载浏览器后访问 example.com 的弱断言、访问线上更新并替换自身测试文件的用例，以及三个依赖浏览器计时或无效上下文的测试。移除泄漏的共享超时上下文，跨源会话测试使用每项独立上下文并注册清理。

有价值的 9 项浏览器集成测试保留，普通 `go test` 不再下载 Chrome。使用 `SLEEPY_CFT_E2E=1` 显式执行，CI 继续启用集成测试。普通默认测试 37 个执行结果通过，其中包含表驱动子项；4 项使用本机 Chrome 的行为测试另外执行通过。剩余 5 项依赖 CfT 下载的集成测试本机未完成，首次镜像和直连下载超时日志保留，不记为通过。

网站原有 sitemap 测试把页面总数写死为 8，现改为与公开页面清单核对，并把双语开源页纳入语言链接、分享元数据和静态页面检查。320 像素下顶栏原先为隐藏的下载按钮留宽，修为窄屏使用菜单内的下载入口；中英文页面均无横向溢出。贡献者显示名继续保留，GitHub 链接由账号标识生成。

## 验证结果与边界

完整执行命令：

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleRelease --offline --no-daemon --no-parallel --max-workers=1 -Pkotlin.compiler.execution.strategy=in-process '-Dorg.gradle.jvmargs=-Xmx6g -XX:MaxMetaspaceSize=2g' --console=plain
```

完整 Android 检查成功，共 567 个测试套件、4,315 个执行项，其中 4,313 通过、2 项 WakeUp 外部握手条件测试跳过，零失败和错误。后续只清理目录测试中的手动复制提示与重复比较，相关 21 项测试再次通过。Lint 零错误，仍有 550 条 Warning 和 40 条 Hint。Room schemas 和学校主资产没有变化。

81 项调试工作流 Python 检查、归因与导出检查、学校目录检查及 20 组实际 Node 采集脚本检查通过。Go vet 和 CI actionlint 通过。

网站最终 `npm run check` 零错误、零警告、2 条提示，`npm run build` 构建 11 页成功；`npm test -- --maxWorkers=1 --no-file-parallelism` 共 31 文件、487 项通过。Cloudflare 本地预渲染首次失败原因是 IPv6 回环请求未匹配现有代理绕过规则，仅在构建命令的 `NO_PROXY` 与 `no_proxy` 补入 `[::1]` 后通过，没有修改系统配置。

浏览器实查中英文页面在 320 像素及桌面宽度无横向溢出，192 项来源、7 位贡献者、折叠展开、语言切换和 GPL 原文入口均通过。全部 7 份许可原文的静态文件存在且与来源字节相等。

模拟器先确认没有正式包名的数据，保留既有 Debug 包。安装本轮基线 Release 包创建测试课表，再覆盖安装优化包，课表仍在，关于页成功发出指向官网许可页的 `ACTION_VIEW`。两个包的本地证书相同。没有清数据或卸载。该冒烟不代替真机登录、全部小组件行为或正式签名验证。
