# Sleepy v1.0.24

### Before-class reminders show a live countdown
Before, a reminder only announced the upcoming course. You can now choose the lead time, see course name, time, room, and teacher, and follow a progress bar until class starts. The headline can use the course name, class time, or room, and the notification icon follows the time of day.

### Fluid Cloud support on ColorOS
On supported OPPO devices, the reminder can appear in Fluid Cloud and Super Island. Other devices continue to receive a system notification.

### Android 16 target preparation
The build moved to compileSdk and targetSdk 37, with minSdk 26. Progress updates run through a foreground service and stop when the class starts.

### Build
- Release tag: `v1.0.24`

# Sleepy v1.0.24

### 课前提醒增加实时倒计时
之前，提醒只会告知即将开始的课程。现在可以设置提前时间，并查看课程名、时间、教室和教师；进度条会一直更新到上课。通知标题可以选择课程名、上课时间或教室，图标也会随时间段变化。

### ColorOS 支持流体云
支持的 OPPO 设备可以在流体云和 Super Island 中显示提醒。其他设备继续使用系统通知。

### Android 16 目标版本准备
构建目标升级到 compileSdk 和 targetSdk 37，minSdk 为 26。进度更新通过前台服务运行，上课开始后停止。

### 构建
- Release 标签：`v1.0.24`

— Lingion
