# 液态玻璃控件的尺寸和间距

液态图标曾直接把 Material 按钮的整体边界作为玻璃盘。多个按钮挨在一起时，静置状态没有足够的视觉空隙，放大和橡皮筋位移还会侵入相邻控件。玻璃盘与点击范围现在分别测量。

## 布局不变量

图标按钮的默认点击范围为 48dp，内部玻璃盘为 36dp，四周各留 6dp。这个空间同时容纳按压放大、弹簧过冲和拖动位移。玻璃保持原来的弹簧和光学材质，所有变换后的像素都必须留在按钮的预留范围内。

```text
|              48dp 点击范围             |
|  6dp  |       36dp 玻璃盘       |  6dp  |
|                 图标                   |
```

相邻按钮没有额外布局间距时，两个静置玻璃盘仍有 12dp 的可见空隙。普通文字操作按钮和筛选标签每侧最多扩展 4dp，配合 8dp 的控件间距使用。密集的自定义控件可以使用同一个运动边界参数。

调用方继续决定页面的位置、宽度和外部间距。明确设置了过小尺寸的调用点需要在页面修复中纠正，公共组件不通过覆盖调用方尺寸来掩盖这些问题。经典样式继续使用其原有 Material 按钮。

## 验证方法

实际 Compose 布局测试测量两个相邻图标盘与点击区域，再按住并向邻居拖动，断言变换后的边界没有交叠。旧实现的玻璃内容宽度为 40dp，目标 36dp 的断言失败，可以复现此次修改所针对的尺寸差异。

工具栏的独立测试继续放置一个允许越界的自定义玻璃控件，检查工具栏不会裁切浮起层。标准图标按钮的运动空间则由尺寸测试单独验证。这两个测试分别保护工具栏的绘制层次与按钮自身的间距。

这些尺寸不适用于 Dock、Toggle、Tab 和 Slider 的浮起镜片。它们保留各自的透镜尺寸、彩虹色散和果冻运动。

共享点击源决定有效按压状态。移出点击区或被父滚动取消后，即使手指还没抬起，镜片也会清除拖动偏移并落回；Initial指针观察器只记录跟随位置，不覆盖取消信号。GlassIconLayoutTest保留按住、移出、保持未抬手的真实手势回归。
