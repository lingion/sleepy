# 作息编辑的控件间距

自动模式的分配格原先固定八列、间隔6dp。窄屏和大字体会把每格压得过小，按压变形还可能伸入邻格。现在按可用宽度计算列数，每格至少48dp，间隔8dp；大字体继续提高最小格宽。格子的运动使用每侧4dp的共同边界，选中的大课间采用主题中与第三色配对的文字颜色。

分钟输入框和删除按钮之间固定保留8dp。删除按钮使用48dp点击范围和公共玻璃盘尺寸。标题仍位于左侧，分钟输入和删除操作仍位于右侧。

```text
| 色点  分组名称           分钟输入框  删除 |
| 节次格  节次格  节次格  节次格         |
| 节次格  节次格  节次格  节次格         |
```

手动模式保持节次编号、开始、结束、删除的顺序。删除按钮统一为48dp；两个时间入口使用紧凑的标签和时间排版，保留原来的字段底色和时间选择弹窗，避免按钮变大后把时间文本截掉。

实际Compose布局测试在264dp容器和1.5倍字体下测量全部十二个节次格，检查最小尺寸、换行、无交叠，以及分钟输入框和删除按钮之间的距离。旧实现的格宽断言失败，修正后的测试与既有作息相关测试合计34项通过。

在280dp窗口、1.5倍系统字体下，手动模式先收紧行内留白，再把节次标题压缩成数字，完整节次仍保留读屏描述。开始和结束时间始终位于删除按钮左侧。时间入口按实际应用字体测量完整时间，空间不足时使用现有的紧凑正文字号，五个字符保持在同一行。

自动模式的窄输入框把标签和数值分为上下两层，单位紧随数值，避免Material输入框的默认内边距把数值挤掉。添加课时和课间按钮先去掉与加号重复的“添加”文字，保留完整操作语义。

```text
手动：[1] [开始 08:00] [结束 08:45] [删除]
自动：[每节时长] [总节数]
      [45 分钟]  [12 节]
      [+ 短课时] [+ 长课时]
```

回归检查使用实际应用字体，读取最后一个可见字符和文字绘制边界。真实Activity路由也检查08:00和08:45的五个字符完整显示，不能只用语义节点存在作为通过条件。
