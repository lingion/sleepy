# 作息编辑的控件间距

自动模式的分配格原先固定八列、间隔6dp。窄屏和大字体会把每格压得过小，按压变形还可能伸入邻格。现在按可用宽度计算列数，每格至少48dp，间隔8dp；大字体继续提高最小格宽。格子的运动使用每侧4dp的共同边界，选中的大课间采用主题中与第三色配对的文字颜色。

分钟输入框和删除按钮之间固定保留8dp。删除按钮使用48dp点击范围和公共玻璃盘尺寸。标题仍位于左侧，分钟输入和删除操作仍位于右侧。

```text
| 色点  分组名称           分钟输入框  删除 |
| 节次格  节次格  节次格  节次格         |
| 节次格  节次格  节次格  节次格         |
```

手动模式保持节次编号、开始、结束、删除的顺序。删除按钮统一为48dp；两个时间入口使用紧凑的标签和时间排版，保留原来的字段底色和时间选择弹窗，避免按钮变大后把时间文本截掉。

实际Compose布局测试在264dp容器和1.5倍字体下测量全部十二个节次格，检查最小尺寸、换行、无交叠，以及分钟输入框和删除按钮之间的距离。旧实现的格宽断言失败，修正后的测试与既有作息相关测试合计34项通过。
