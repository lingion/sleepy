# 液态玻璃页面的间距修正

保留页面导航、动作顺序和现有配色。常规图标使用共享的48dp点击区与36dp玻璃盘。

位置不变量：

```text
导入格式行：格式名  说明  [详情]
课表卡片：状态  标题与学期信息  [复制][更新][设置]
                创建时间
节假日数据源：标题与来源  [刷新或加载状态]
```

格式详情原来是16dp裸图标，现在使用标准图标按钮；两段说明按比例分配剩余宽度。课表创建时间使用卡片底部的完整行，避免与三个动作争用标题宽度。刷新和加载状态使用相同48dp槽位，避免状态切换时文字横跳。冲突课程列表和节次样式预览保留8dp间距，每个自绘玻璃表面的运动限定在4dp留白内。

颜色弹窗色相滑条保留48dp高度，去掉包在滑条外部的裁切；浮起40dp镜片的上下边缘不会被原来的36dp宿主截断。饱和度面板仍独立裁切。

用户原话与实现行为：图标不能打架，对应独立点击区与可见盘面；间距不能过小，对应8dp布局间隙与有界运动；保留整体布局，对应动作顺序和导航不变，长日期在原卡片内单独排放。

验证：ColorPickerLayoutTest直接渲染真实颜色弹窗并测量色相滑条宿主；旧36dp高度失败，48dp高度通过。完整设备截图在集成验证中保存，不能以该几何测试代替透镜的视觉验收。
