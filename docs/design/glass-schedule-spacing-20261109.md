# 课表顶栏的空间分配

位置和顺序不变量：切表与撤回操作居左，加课与分享居右，翻周器相对页面宽度居中。撤回胶囊保持完整比例。按钮使用共享尺寸，周选择菜单每格留4dp运动空间。

```text
足够宽： [切表][撤回/重做][确认]   [上一周][周次][下一周]   [加课][分享]
窄屏：   [切表][撤回/重做]                               [加课][分享]
                            [上一周][周次][下一周]
```

三槽布局先测量实际控件宽度。只有中央区域和左右对称留白都够时才用一行。空间不足时，翻周器居中另起一行；极窄屏且左右动作本身也放不下时，左右动作分行，所有功能仍可见。状态文字可以换行，不删除学期外状态或周数。

用户原话与实现行为：控件不能打架，对应实际测量与自适应换行；统一尺寸和间距，对应共享图标与8dp间距；保留整体布局，对应原操作顺序、左右锚点与居中翻周关系。

真实几何红测曾复现：360dp下下一周与加课重叠，280dp与1.5倍字体下切表与上一周重叠。修复测试覆盖上述条件及840dp的原单行居中布局，并检查全部动作之间的边界和48dp点击区。
