# 课表顶栏的空间分配

位置和顺序不变量：切表、撤回和确认居左，加课和分享居右。上一周、周次、下一周始终按此顺序出现。宽屏翻周器相对页面居中；窄屏允许在左右动作之间移动，优先保留单行。撤回胶囊不压扁。

```text
完整单行： [切表][撤回/重做][确认]   [上一周][第 2 周][下一周]   [加课][分享]
缩短文字： [切表]                     [上一周][2][下一周]      [加课][分享]
合并控件： [切表][撤回/重做][确认]         [左 | 2 | 右]         [加课][分享]
最终换行： [切表][撤回/重做][确认]                              [加课][分享]
                                      [上一周][周数][下一周]
```

三槽布局测量实际左右动作和当前字体下的周次文字。空间不足时先收紧外边距，再只显示数字，最后把翻周三个动作合为与撤回胶囊相同的单片玻璃。只有所有压缩方式仍不能容纳时才换行；极窄屏且左右动作也放不下时再拆左右行。

普通按钮保持48dp点击区、36dp盘面。最终紧凑模式的两侧按钮为40dp点击区和28dp盘面，仍保留每侧6dp运动空间；三段胶囊每段至少32dp，分隔线1dp，整组共享按压反馈。完整周次和学期状态始终保留为读屏描述。周次点击行为不变：当前周打开选择菜单，其他周跳回实际周。菜单每格留4dp运动空间。

用户原话与实现行为逐条核验：

- “能不换行就不换行”：先尝试完整文字、压缩间距、数字文字、三段胶囊，全部不够才换行。
- “去掉第和周，只留一个2”：数字模式只显示当前周的数字，完整语义由读屏保留。
- “左键、2、右键合并”：三个动作共用完整胶囊和按压源，内部顺序固定。
- “就像撤回和反撤回”：使用相同的单片玻璃、分隔线、主题色和共享反馈。

真实几何回归覆盖360dp普通状态、360dp同时出现撤回和确认、280dp与1.5倍字体，以及840dp宽屏。压缩前的360dp两项新需求测试真实失败；测试检查数字、三段顺序、动作无重叠、单行和最终换行。禁用重做不能抬起共享胶囊，可用撤回仍保留光学反馈。
