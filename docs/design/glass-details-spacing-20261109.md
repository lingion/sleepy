# 主题与设置页液态控件间距

预设和自定义主题卡保留双列、三色板、名称和选中状态。首行固定至少48dp，右侧48dp编辑槽与色板组之间保持8dp，色板只在窄列内缩小宽度。预设卡保留同宽空槽，两个卡片始终等高。名称最多一行，长名称省略。

位置不变量：

```text
首行 [色板 色板 色板]  8dp  [编辑或占位]
次行 [名称                         选中]
```

提醒页的去设置、作息策略的修改使用标准文字按钮并保留48dp点击高度；原设置跳转、兼容回退和修改回调保持原路径。策略说明文字占据剩余宽度，与动作之间留8dp。小组件组标题占据剩余宽度，折叠箭头固定在右侧。

用户原话与实现行为：图标不能打架，对应真实主题卡内色板与编辑目标分离；尺寸和间距统一，对应共享按钮和8dp动作间距；保持整体布局，对应原网格、卡片顺序和页面入口。

真实主题卡在138dp与158dp列宽下分别验证1.5倍和默认字体。旧实现两项失败，包含编辑按钮被挤出卡片；几何回归直接调用生产组件，不复制布局。
