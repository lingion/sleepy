# 液态下拉菜单的前景绘制

下拉菜单的位置、内容顺序、入场退场、超椭圆轮廓、背景采样和折射参数保持原实现。Material继续管理窗口、焦点与返回关闭；玻璃仍在绘制时按原轮廓裁切。只对下拉菜单关闭backdrop额外的子内容placement图层，其他控件保留默认值。

```text
菜单窗口
  原超椭圆玻璃背景
  Material内容图层：标题、数字和按钮
```

API33模拟器上的真实窗口像素对照表明，额外图层与Material下拉菜单组合时，前景回调虽执行，内容仍丢失。单独移除scene录制或改普通圆角不能修复。关闭下拉菜单的额外图层后，80dp红色和绿色前景各恢复24904个像素；经典模式均为25600。此结果确认了触发组合，未确定更底层的Android或Skia原因。

同一GPU回归同时覆盖下拉菜单、普通提醒弹窗、日期弹窗和语言菜单，检查入场后前景可见且由红变绿时实际像素同步更新。26项相关Robolectric测试、新增1项GPU回归和既有3项材质GPU回归通过。最终组合页面截图另行复核；其他API与实体设备未在此项实验中验证。

用户要求与实现行为：液态组件的大小、间距与页面布局保持一致，对应保留原菜单尺寸与内容树；完整玻璃块和折射效果对应保留原轮廓、shader与背景采样；实际视觉检查对应窗口像素红绿对照，语义节点存在不再单独作为内容可见的证据。

语言卡片先按实际文字宽度尝试同行，无法同时容纳完整标题和当前语言时再把当前语言移到下方。标题中的Language保持完整，菜单继续以当前语言为锚点，选择、退出与读屏行为不变。
