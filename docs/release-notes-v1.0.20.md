# Sleepy v1.0.20

### Reminders have their own page
Before, notification permission could appear on first launch. Reminders now live under Mine → Reminder, are off by default, and request permission only when enabled.

### Daily and before-class reminders use timetable data
Daily reminders and configurable before-class reminders now include the course name, time, room, and other details from the active timetable.

### About page
The new About page shows the version, author, repository link, and GPL-3.0 license information.

### Build
- Release tag: `v1.0.20`

# Sleepy v1.0.20

### 提醒功能单独成页
之前，通知权限可能在首次启动时出现。现在提醒入口位于「我的 → 提醒」，默认关闭，只有开启提醒时才请求权限。

### 每日提醒和课前提醒使用真实课表数据
每日提醒和可配置提前时间的课前提醒，会读取当前课表中的课程名、时间、教室等信息。

### 新增关于页面
关于页展示版本、作者、仓库链接和 GPL-3.0 协议信息。

- Release 标签：`v1.0.20`
