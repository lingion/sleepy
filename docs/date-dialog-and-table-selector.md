# 日期模式切换与课表选择弹窗修复

2026-11-14，Android。仅记录本轮两项修复，不代表全部玻璃控件已完成原生等效验收。

## 日期输入切回日历

复现路径：编辑日期，点击铅笔，点击输入框显示键盘，再点击日历。Material Design 与 Liquid Glass 均能复现慢展开、日期网格行位置跳动。

`SleepyDatePicker` 继续使用官方 Material DatePicker。切回日历前清除离场输入框焦点并隐藏键盘，关闭 Material 输入内容的延迟自动聚焦；用户点击输入框仍可正常输入。外部直接修改原 DatePickerState 时也清理焦点。

慢展开的另一个原因是日期 Dialog 的 wrap-content 窗口把当前动画高度再次作为日历测量约束。真实设备日志中，父高度上限在完整可用高度与当前动画高度之间交替，导致目标反复变化。日期 Dialog 现在使用稳定的 MATCH_PARENT 窗口高度，面板仍按内容高度包裹、居中；保留官方模式转换动画、窗口宽度、系统边距与键盘策略，窗口销毁时恢复原尺寸。

同一 API 36 设备、系统动画倍率均为 1.0，带临时测量日志的单变量对照中，展开从约 3.25 秒缩短到约 0.24 秒。最终去掉诊断代码后，两种模式的真实录像中未再出现日期网格首行跳动。此数字只描述该次测量，不能推导所有设备耗时或与 iOS 每毫秒等效。

## 首页课表选择弹窗

仅此列表型玻璃弹窗选择官方 Material AlertDialog 的窗口与内容布局，继续使用玻璃材质；其他玻璃确认框沿用各自布局。Material Design 分支不变。

1216 px 宽设备的两种模式实际面板均为 952 × 461 px，左右各 132 px，标题与列表内距均为 71 px。列表选择回调及 2 倍字体下的几何一致性有独立测试。

- 26 项定向 JVM 测试通过：6 项日期焦点/多帧网格位置、2 项课表选择布局、18 项既有玻璃弹窗内容测试。
- `:app:assembleDebug` 与 `:app:assembleDebugAndroidTest` 通过。
