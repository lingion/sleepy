# Sleepy v1.0.12

### Harbin Engineering University direct import
Before, Harbin Engineering University could not be imported because its Wisedu system returned JSON while the existing importer expected HTML. The app now logs in through the university portal and fetches the timetable through the Wisedu JSON API.

### Build
- Release tag: `v1.0.12`
- versionName: `1.0.12`
- versionCode: `12`
- APK: `sleepy-v1.0.12-arm64-release.apk`

# Sleepy v1.0.12

### 支持哈尔滨工程大学直连导入
之前，哈尔滨工程大学无法导入，因为它的金智 Wisedu 教务系统返回 JSON，而原有导入器只处理 HTML。现在可以通过学校门户登录，并使用 Wisedu JSON API 获取课表。

### 构建
- Release 标签：`v1.0.12`
- versionName：`1.0.12`
- versionCode：`12`
- APK：`sleepy-v1.0.12-arm64-release.apk`
