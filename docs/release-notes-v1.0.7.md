# Sleepy v1.0.7

### Choose the app theme
Before, Sleepy used one fixed app color scheme. The Theme Colors page now offers Default Lavender, Spring Green, Ocean Blue, Peach Pink, Slate Gray, and Follow System. The choice applies immediately and is remembered across restarts.

### Follow System uses Material You where available
On Android 12 and later, Follow System derives the app colors from the device wallpaper. Android 7–11 fall back to Default Lavender because Material You dynamic colors are unavailable there.

### Course colors remain unchanged
The six app themes do not alter the ten existing course-card colors.

### Build
- Release tag: `v1.0.7`
- The tagged Gradle configuration reports versionName `1.0.6` and versionCode `6`

# Sleepy v1.0.7

### 可以选择应用主题
之前，Sleepy 只有一套固定的应用配色。现在「我的 → 主题颜色」提供默认淡紫、春绿、海蓝、蜜桃粉、石板灰和跟随系统六种选择。切换立即生效，重启后也会保留。

### 跟随系统在支持的设备上使用 Material You
Android 12 及以上选择跟随系统时，会从设备壁纸生成应用配色。Android 7–11 不支持 Material You 动态取色，会回退到默认淡紫。

### 课程颜色保持不变
这六套应用主题不会改变原有的十种课程卡片颜色。

### 构建
- Release 标签：`v1.0.7`
- 标签对应 Gradle 配置记录的 versionName 为 `1.0.6`、versionCode 为 `6`

— Lingion
