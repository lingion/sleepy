# Sleepy v1.0.14

### HEU's 13-period timetable is available as a preset
Before, Harbin Engineering University users had to enter their period schedule manually. Selecting the university now provides a built-in 13-period preset based on the 2025–2026 spring-semester schedule.

### Direct import completes the full flow
Before, import could stop after parsing. The flow now goes from parsing to period configuration, semester start date, and timetable name, then writes the result after confirmation.

# Sleepy v1.0.14

### 哈工程新增 13 节课表预设
之前，哈尔滨工程大学用户需要手动填写节次时间。现在选择学校后会提供内置的 13 节课表预设，依据 2025–2026 学年春季学期作息。

### 教务导入完成完整流程
之前，导入可能在解析后就中断。现在会依次进入节次配置、学期开始日期和课表名称设置，确认后才写入课表。
