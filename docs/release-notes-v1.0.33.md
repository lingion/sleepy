# Sleepy v1.0.33

### Widgets can use neutral course colors
Before, all five widgets used per-course hues to distinguish classes. A new Widget Settings toggle can replace those colors with the theme's neutral surface color. The in-app schedule remains colored; this setting affects widgets only.

### WeekView spacing is consistent
The plain-text WeekView widget now uses the same 3dp course gap as the other widget renderers.

### WeekView has an optional separator
The separator is now a visible 1dp line by default and can be disabled in Widget Settings. The course gap remains unchanged when it is disabled.

### Build
- Release tag: `v1.0.33`
- versionName: `1.0.33`
- versionCode: `34`
- ABI APKs: `app-arm64-v8a-release.apk`, `app-armeabi-v7a-release.apk`, `app-x86_64-release.apk`

# Sleepy v1.0.33

### 小组件支持统一中性色
之前五种小组件都用课程色相区分课程。现在「小组件设置」可以关闭课程色，改用主题的中性色。App 内课表仍然显示课程颜色，这个设置只影响小组件。

### 周视图小组件间距统一
纯文字周视图现在与其他小组件使用相同的 3dp 课程间距。

### 周视图支持分隔线开关
分隔线现在默认显示为清晰的 1dp 线，也可以在小组件设置中关闭。关闭后课程间距不会改变。

### 构建
- Release 标签：`v1.0.33`
- versionName：`1.0.33`
- versionCode：`34`
- ABI APK：`app-arm64-v8a-release.apk`、`app-armeabi-v7a-release.apk`、`app-x86_64-release.apk`
