# Sleepy v1.0.23

### Jump through the school list with a letter index
Before, finding a school required scrolling through the list. The right-side index now jumps to a letter group by tap or swipe, and shows only letters that have matching schools.

### Letter hit zones and pinyin order are fixed
Before, a tap could land on the wrong letter group, and schools sharing an initial were not in dictionary order. The hit mapping now spans the full bar, and each group sorts by full pinyin.

### Build
- Release tag: `v1.0.23`
- APKs: `app-arm64-v8a-release.apk`, `app-armeabi-v7a-release.apk`, `app-x86_64-release.apk`

# Sleepy v1.0.23

### 学校列表新增字母索引
之前只能不断滚动查找学校。现在右侧字母条支持点击或滑动跳转到对应分组，并且只显示确实有学校的字母。

### 字母触摸范围和拼音排序修正
之前点击字母可能跳到错误分组，同一首字母下的学校也不一定按字典顺序排列。现在字母触摸范围覆盖整个索引栏，分组内按完整拼音排序。

### 构建
- Release 标签：`v1.0.23`
- APK：`app-arm64-v8a-release.apk`、`app-armeabi-v7a-release.apk`、`app-x86_64-release.apk`

— Lingion
